# LTE 鎖頻管家 (LTE Band Manager)

專為華為 4G/LTE 路由器（HiLink 架構）打造之 Android 鎖頻、射頻訊號監控、載波聚合偵測、天線調校與設備管理工具。採用現代科技紅藍風格（Slate Tech Palette）打造流暢、直觀且專業的使用體驗。

---

## 支援機型

- **Huawei B818-263**（Cat.19，硬體支援至 4CA / 5CA 偵測與智慧跑分）
- **Huawei B618s-66d**（Cat.11，硬體支援至 3CA）
- **其他相容 HiLink API 之華為 4G 路由器**（如 B525、B535、B715 等）

---

## 主要功能特色

### 1. 智慧鎖頻管家 (Band Lock)
- **自動對齊鎖定狀態**：開啟彈窗時自動讀取並勾選路由器當前鎖定與生效之頻段，不再預設全選。
- **多頻與單頻彈性組合**：完整支援 FDD/TDD 常見頻段（B1、B3、B7、B8、B20、B28、B32、B38、B40、B41、B42、B43）。
- **專業快捷操作列**：提供「全選」、「清空」、「還原鎖頻」（一鍵重設回路由器目前鎖定組合）快速操作。
- **運作中標籤標示**：清單中清楚標註目前正在使用的頻段（「運作中」徽章），便於識別主頻與輔助載波。
- **防呆保護**：未勾選任何頻段時停用套用按鈕，防止空頻段提交造成路由器斷線。

### 2. 射頻訊號與基站即時監控 (Cellular RF)
- **4G 階梯訊號指標**：首頁、訊號卡片與桌面小工具皆整合 0 至 5 格直條階梯圖形指標。
- **完整 RF 數據**：即時掌握 RSRP、RSRQ、SINR、RSSI、PCI、EARFCN、主頻段與頻寬（如 20MHz/15MHz）。
- **即時訊號走勢圖**：內建 RSRP 與 SINR 歷史波動折線圖，協助微調路由器擺放角度與方向。

### 3. 載波聚合 (CA) 監測與智慧跑分 (Band Advisor)
- **多載波聚合辨識**：精準解析下行調變頻道（`dl_mcs` 0-indexed）與多重次載波標籤，支援 4G+ / 2CA / 3CA / 4CA / 5CA 動態狀態展示。
- **電信專屬 4CA 跑分評估**：內建台灣主要電信（中華電信 B1+B3+B7+B8、遠傳電信 B1+B3+B7+B28 等）測速組合，自動逐一切換鎖頻並繪製評估報告。

### 4. 天線模式切換與調校 (Antenna Alignment)
- **多種天線模式**：支援「內建天線 (INTERNAL)」、「外接天線 (EXTERNAL)」、「混合模式 (MIXED)」與「自動 (AUTO)」切換。
- **即時回饋機制**：採用樂觀更新（點擊瞬間立即響應樣式）配合觸覺微震動，並修復 B818/B618 狀態讀取誤判。

### 5. 連線裝置管理與踢除 (Connected Devices)
- **分層防破版排版**：獨立展示主機名稱、IPv4/IPv6 與 MAC 位址，妥善處理長 IPv6 字串重疊問題。
- **一鍵踢除下線 (KICK)**：整合路由器 MAC Filter 黑名單過濾端點，支援踢除未授權裝置並附帶防呆確認彈窗。

### 6. 簡訊收發管理 (SMS Inbox)
- **SIM 卡簡訊管理**：即時檢視路由器未讀/已讀簡訊，刪除簡訊具備二次確認防呆對話框。

### 7. 基地台地圖查詢 (Cell Map)
- **基站地理反查**：依據當前連線之 eNodeB 與 Cell ID，一鍵跳轉外部基地台地圖（如 CellMapper）定位基站方向。

### 8. 個人化設定 (Preferences)
- **外觀風格切換**：科技深色主題（Slate 暗色紅藍風格）/ 清爽淺色主題 / 跟隨系統。
- **語言偏好**：繁體中文 / English 切換（RSRP、SINR、PCI 等射頻名詞維持國際標準英文）。
- **網速單位切換**：支援 Mbps（電信頻寬標準）與 MB/s（檔案下載習慣）切換。

### 9. Android 桌面小工具 (App Widget)
- 提供桌面即時監控小部件，無需開啟主程式即可在手機桌面查看 4G 訊號格數、主頻段、CA 狀態、即時網速與在線裝置數量。

## 常見問題 (FAQ)

### 1. 為什麼平常只顯示 1CA 或 2CA，測速時才跳 3CA / 4CA？
電信基地台為了省電與頻譜資源調度，在待機或小流量狀態下僅會維持 1 個主載波（PCC）或基礎聚合；只有在下行大流量（如執行 Speedtest 或下載大檔案）瞬間，基地台才會透過 RRC Connection Reconfiguration 動態下發輔助載波（SCC）跑滿 3CA 或 4CA。

### 2. 華為 B818-263 如何鎖定 4CA？
在「4G 頻段鎖定」彈窗中，同時勾選您所屬電信業者支援之 4 個頻段（例如中華電信勾選 B1+B3+B7+B8；遠傳電信勾選 B1+B3+B7+B28），套用後進行高頻寬測速即可觸發 4CA。

## 專案建置與安裝

本專案使用 Gradle 與 Jetpack Compose 開發。

### 編譯除錯版 APK

```powershell
.\gradlew.bat assembleDebug
```

產物路徑：`app\build\outputs\apk\debug\app-debug.apk`

### 透過 ADB 安裝至手機

```powershell
adb install -r -t -d app\build\outputs\apk\debug\app-debug.apk
```
